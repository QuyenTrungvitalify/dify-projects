# G01 — テーマを渡すと調べて要点+出典をまとめる (JA) [nguồn: AdvancedSearch]

```
気になるテーマ（例：「2025年の電気自動車の補助金」）を入れたら、
ネットで調べて、要点を5つくらいの箇条書きにまとめてほしいです。
それぞれの要点が、どのサイトの情報なのか（出典URL）も付けてください。
あとで自分で裏取りしたいので。ソースがはっきりしないことは書かないでください。
```

## Bối cảnh giả định
Người làm nội dung, cần research nhanh có nguồn. Nguồn: 搜索大师 thật (iteration+http+search tool).

## Trục năng lực được thử
**Tìm web + tổng hợp + trích nguồn** (search tool ngoài) — trục MỚI: build có bịa nguồn không, dùng
search tool thật hay giả · "ソース不明なことは書かない" (không nguồn thì đừng viết) = honesty.

## Hình dạng build tốt
search tool (Google/Tavily…) → iteration đọc kết quả → LLM tổng hợp 5 điểm + gắn URL nguồn thật từ
kết quả search. KHÔNG bịa URL. Cần search tool = provider ngoài, nêu rõ.

## Bẫy đã biết
Bịa URL nguồn (LLM tự chế link) = fail nặng nhất mảng này · search tool cần key ngoài · "không nguồn
đừng viết" phải trong prompt.

## MANUAL dự kiến
Gắn search tool thật · chủ đề thật xem URL có thật + bấm được không.

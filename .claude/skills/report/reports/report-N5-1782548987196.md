## What this workflow actually does (from the YAML graph)

1. Takes an article URL (+ optional style note).
2. HTTP GET fetches the raw HTML.
3. A Python code node (stdlib `re`/`html` only) strips script/style/tags, prefers `<body>`, extracts plain text + `<title>`/`<h1>`, caps body at 12k chars, and returns an `extract_error` flag on empty input.
4. LLM #1 rewrites/paraphrases imitating the source's tone & structure in the same language.
5. LLM #2 turns the rewrite into one concise English text-to-image prompt.
6. The DALL·E-3 tool generates one 1024×1024 hero image.
7. END returns `rewritten` (string) + `image` (array[file]) + `title`.

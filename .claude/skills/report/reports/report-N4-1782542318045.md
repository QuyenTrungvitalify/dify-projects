## What this workflow actually does (from the YAML graph)

1. **Start** — one required URL text input (`url`, ≤2000 chars).
2. **HTTP GET** — fetches the URL no-auth with a browser UA + 10s/30s timeouts; emits `body`, `status_code`.
3. **Code (py3, stdlib)** — regex-strips `<script>/<style>/<head>` then all tags, `html.unescape`, collapses whitespace; guards non-2xx/empty body (`fetch_ok`), truncates to 12,000 chars; emits `clean_text`, `char_count`, `fetch_ok`.
4. **LLM** — Japanese summary (1-line gist + 3–5 bullets); instructed to say "取得失敗" rather than hallucinate when fetch failed, and not to invent facts.
5. **End** — `summary` + transparency fields `source_url`, `char_count`, `status_code`.

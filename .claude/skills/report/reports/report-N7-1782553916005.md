## What this workflow actually does (from the graph)

A multi-turn advanced-chat bot. Each user turn: **LLM 1** runs a hidden "thinking scratchpad" over `sys.query` (decompose intent, list conditions, self-check, no final answer); **LLM 2** then writes the polished final answer using `sys.query` + LLM 1's reasoning text, instructed to override the scratchpad if it spots an error and to never reveal it; the **answer** node shows only LLM 2's output. Both LLMs keep a 10-turn memory window.

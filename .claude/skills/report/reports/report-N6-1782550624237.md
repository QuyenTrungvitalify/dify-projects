## What this workflow actually does (from the graph, not the SPEC)

1. Chat entry (`sys.query` + `sys.files`) → **if-else** asks "is a file attached *this turn*?" (`sys.files` not empty).
2. **True** → `document-extractor` pulls the file's text → `assigner` over-writes `conversation.doc_text` (persists across turns). **False** → straight to the LLM, reusing the doc_text saved earlier.
3. One **LLM** (memory ON) answers `sys.query` grounded strictly in `conversation.doc_text`; empty-doc and not-in-doc cases handled by the system prompt → streamed via `answer`.

Net: upload once, ask many — a per-conversation document Q&A chatbot.

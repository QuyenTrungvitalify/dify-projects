## What this workflow actually does (from the YAML graph)

1. User uploads a document (PDF/docx/txt/md) and gives `target_lang` (required) + `source_lang` (optional, "auto").
2. `document-extractor` pulls plain text; a Python **Split** node packs it into ≤30 paragraph-aware chunks (grows chunk size for very long docs so it never exceeds the 30-item iteration cap, never cuts mid-sentence).
3. An **iteration** (parallel ×3, continue-on-error) runs the LLM once per chunk — faithful, complete, structure-preserving translation into the target language.
4. A Python **Join** node concatenates the translated chunks in original order, dropping any failed chunk; **End** returns `translated_text` + `chunk_count`.
